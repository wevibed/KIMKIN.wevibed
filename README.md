# Kimkin Technologies

Mobile-first React/Vite storefront for Kimkin Technologies, Eastgate Market, Harare.

## Build

```bash
npm install
npm run build
```

Deploy the generated `dist` folder to Cloudflare Pages, or connect the repository to Cloudflare Pages with the build command `npm run build` and output directory `dist`.
